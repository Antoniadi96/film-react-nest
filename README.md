# Film! React + Nest.js Project

Учебный проект для Яндекс.Практикума (Спринт 17) - полноценное веб-приложение для киноафиши с бэкендом на Nest.js, фронтендом на React/Vite и автоматизированным деплоем.

## 🚀 Демо

- **Приложение:** http://antoniadi.students.nomorepartiessbs.ru
- **API:** http://antoniadi.students.nomorepartiessbs.ru/api/afisha
- **Репозиторий:** https://github.com/Antoniadi96/film-react-nest
- **GitHub Actions:** https://github.com/Antoniadi96/film-react-nest/actions
- **Docker образы:** https://github.com/Antoniadi96/film-react-nest/pkgs/container/film-react-nest

## 🎯 Технологии

### Backend
- **Nest.js** - фреймворк на Node.js
- **TypeScript** - статическая типизация
- **PostgreSQL** - основная база данных
- **TypeORM** - ORM для работы с базой данных
- **Jest** - unit-тесты

### Frontend
- **React** + **TypeScript** - UI-фреймворк
- **Vite** - сборщик
- **CSS Modules** - стилизация

### DevOps
- **Docker** - контейнеризация
- **Docker Compose** - оркестрация контейнеров
- **GitHub Actions** - CI/CD
- **GitHub Container Registry** - реестр Docker-образов
- **Yandex Cloud** - облачный хостинг
- **Nginx** - reverse proxy и статика
- **UFW** - фаервол для безопасности
